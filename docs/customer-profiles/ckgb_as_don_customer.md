# CKGB as DON Customer

Status: target concept
Scope: CKGB as an independent target repository for DON

CKGB should become a real customer of DON, not just a documentation by-product.

DON should eventually inspect CKGB as a target repository and provide project-state assessment, patch-readiness assessment, governance gap review, baseline completeness review, lessons-learned consistency review and a target-profile-specific operator brief.

CKGB is a knowledge, governance and project-bootstrap repository. This tests DON genericity because DON must evaluate a non-pipeline, non-self, governance-heavy target.

Profile ID candidate: current_known_good_baseline
